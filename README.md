# Özlem

Küt saçlı Özlem uçan halısıyla yolda uçuyor. Müzik notası, DJ kulaklığı, makarna ve pizza topladıkça mutluluğu artar; turuncu giyen köylülere çarparsa azalır. Mutluluk 30'u geçince Özlem halının üstünde dans etmeye başlar. Mutluluk 0'a düşerse oyun biter.

## Oynamak

`index.html` dosyasını tarayıcıda aç.

- Ok tuşları / WASD ile yönet
- Telefonda ekrana dokunup sürükle

| Obje | Mutluluk |
|---|---|
| Müzik notası | +3 |
| DJ kulaklığı | +4 |
| Makarna | +3 |
| Pizza | +4 |
| Turuncu köylü | −6 |
